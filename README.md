## 🖊️ Description

This is a mod for Assetto Corsa that provides highly customizable force-feedback effects and enhancements. It works through an in-game UI app where players can customize various aspects of their FFB.

This is not a complete FFB replacement, but instead it uses AC's FFB as a baseline and just adds a number of optional tweaks and effects on top.

The main features of this mod include:

 - Automatic per-car FFB gain
 - Different filtering options such as general FFB filtering or ABS vibration filtering
 - Downforce compensation with multiple modes (aimed at weaker wheelbases to avoid clipping)
 - Multiple effects to convey braking
 - Extra self-aligning torque to highlight understeer
 - Oversteer force effect
 - Various haptic vibration effects such as brake feedback, throttle feedback, gear shift warning etc.
 - Safety features such as dampening collision forces
 - Global and per-car versions of each setting
 - Access to AC's own FFB settings from right within the app
 - Saving settings to preset files that are easy to share with others

## 📖 Why?

AC already has one of the best force-feedback experiences of any simulator. The FFB it provides is very dynamic, direct and descriptive of the car which enables a level of reactive driving that some other sims don't really support. This is why I wanted to keep AC's own FFB as a baseline, and just add some useful options on top to convey even more information about the state of the car, or just make life easier in some ways.

## 🖥️ Installation

This mod requires [***Content Manager***](https://assettocorsa.club/content-manager.html) and [***Custom Shaders Patch***](https://acstuff.ru/patch/) to be installed!

First, download the latest version from [***Releases***](https://github.com/adam10603/AC-Adams-FFB-Toolbox/releases) or from [***Overtake***](https://google.com/).

Once you have the zip file you can drag it into Content Manager to install it.

From here everything is done from the UI app. Just launch into a session and look for the app called ***Adam's FFB Toolbox Config*** in the side menu.

![Adding the UI app](https://i.imgur.com/RB1lKpO.png)

## 🎮 Usage

The app will show you a short first-time setup screen, but after that you can start using it. Every setting has tooltips describing what they do, so make sure to read those for explanations.

![UI app](https://i.imgur.com/6jgCzFg.png)

The ***Global*** tab has your global settings that every car will use by default.

On the ***Car-specific*** tab you can set overrides to any setting that only apply to your current car.

The ***Presets*** tab lets you save your settings to preset files. You can also open the presets folder from here which lets you easily share your presets with others, or drop in presets you got from elsewhere.

On the ***Graph*** tab you can set up a graph window to see how the plugin is changing your FFB in real-time.

![Graph window](https://i.imgur.com/UkB92a0.png)
